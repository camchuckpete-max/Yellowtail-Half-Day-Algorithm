# Thrifty Season 1 Strategy

## Data Analysis (Day 1)

### Yellowtail by Trip Class (Historical Data)
- **Day 1.5 trips**: avg 16.25 yt, cost $550 → $33.85/fish ⭐
- **Three-quarter**: avg 3.73 yt, cost $150 → $40.26/fish ⭐
- **Overnight**: avg 6.27 yt, cost $400 → $63.77/fish
- **Half-days (AM/PM)**: avg 0.13 yt, cost $80 → ~$600/fish ❌

### Key Insight
My "many cheap tickets" persona conflicts with actual data! Half-days are terrible value. 1.5-day Friday trips are best because:
- $550 for 16 yt average = $34/fish
- 0 PTO cost (Friday departure, Saturday fishing, Sunday return - all non-weekdays)
- Reliable and available

### Budget Strategy
With $2000 budget and 10 PTO:
- 3 × 1.5-day Friday ($1650) = ~48 yt, 0 PTO
- 2 × three-quarter ($300) = ~8 yt, 2 PTO
- **Total: ~56 fish, $1950, 5 PTO left**

## Current Strategy
1. Prioritize 1.5-day Friday trips (DAY_1_5 offer)
2. Book three-quarter trips when budget/PTO allow
3. Commit PTO for upcoming weekdays 14+ days ahead
4. Avoid half-days entirely
