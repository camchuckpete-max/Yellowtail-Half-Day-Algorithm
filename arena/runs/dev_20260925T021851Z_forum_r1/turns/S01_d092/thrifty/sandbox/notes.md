## Lessons for Season 2

### What Went Right
1. Identified failing strategy at day 61 (pivot from volume to premium)
2. Correctly recognized data showing premium trips catch more fish
3. Booked the correct trip classes (1.5-day, 3/4-day are proven high-volume)

### What Went Wrong
1. **Boat selection**: Booked boats that happened to not catch fish. Need to track per-boat catch rates.
2. **Late pivot timing**: Waited until day 61 to pivot. Should start with premium if data supports it.
3. **Season start strategy**: Didn't recognize early season was dead. Half-days days 35-57 mostly caught 0.
4. **PTO management**: Committed PTO early (d017-d020) with no flexibility for better weekday opportunities.

### Season 2 Strategy Framework
1. **Start premium immediately**: Begin with 1.5-day or overnight trips, not half-days
2. **Track boat performance**: Build a running average of YT/trip per boat per class
3. **Select boats not just classes**: Use historical catch rates to pick the best boats
4. **Early season signal**: If first 2-3 weeks show near-zero catches, pivot faster
5. **PTO timing**: Commit PTO strategically 14 days ahead for prime weekday dates (May-Sept peak)
6. **Budget allocation**: 
   - Premium budget first (70% of $2000 = $1400 for 1.5-day/overnight)
   - Reserve half-days only if budget/time remains
   - Multi-day trips if any budget allows (highest catch rate: 26+ YT per trip)
